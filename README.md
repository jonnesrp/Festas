# Festas · João Siqueira convida!

Site com as festas da semana: Lista VIP e ingresso com desconto.

- As festas vêm da planilha "Site - Festas" no Google Drive (uma linha por festa e por data). Para mudar o site, basta editar a planilha.
- `dados.js` é uma cópia de reserva, usada só se a planilha não responder.
- `flyers/` guarda as imagens das festas. A coluna "Flyer (link)" da planilha tem prioridade quando preenchida.
